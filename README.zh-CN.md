## 🧭 我怎么学

我很少从 0 到 1，而是从巨人肩膀起步：先找别人现成的 skill、模板、开源书，改成自己的，再拿真实项目检验。

|  | 项目要用时 | 平时有空时 |
|---|---|---|
| **实践** | 拿真实需求直接做，卡住了再补 | 拆别人的 skill 和模板，改成自己的版本 |
| **认知** | 遇到不懂的，让 AI 讲清原理再往下走 | 翻术语表、读开源书，先知道有哪些概念 |

大部分时间在左上角：真实项目推着我学。
